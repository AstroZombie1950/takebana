# Takebana

Платформа прямых эфиров: производители, заведения, блогеры и эксперты выходят в лайв,
зрители смотрят и общаются. Сервер на Node.js, база MongoDB, ретранслятор Daily.co,
собственный RTMP→HLS конвейер для массовых трансляций.

Репозиторий заведён с нуля 4 сентября 2026. Истории от прежней команды нет —
исходники получены архивом, оригинал лежит в `temp/views.zip` вне репозитория.

## Что где

| Папка | Что это |
|---|---|
| `server/` | Приложение: Express + EJS + Socket.IO + MongoDB. Код клиента, приводим в порядок |
| `ops/` | Эксплуатация: настройка сервера, деплой, бэкапы, проверка. Порядок — [ops/README.md](ops/README.md) |
| `docs/` | Документация проекта: карта кода, аудит, роадмап, чек-лист переезда. **В репозиторий не идёт** |
| `temp/` | Черновики, архивы, документы для клиента, секреты. **В репозиторий не идёт** |

## Быстрый старт

Нужны Node 24 LTS (на проде именно 24, версия в `.nvmrc`) и MongoDB.

```bash
cd server
cp .env.example .env      # заполнить ключи
npm install
npm run dev               # nodemon, перезапуск при правке файлов
```

Открыть http://localhost:3000 — это главная страница сайта.

## Состояние

**Переезд состоялся 9 сентября 2026.** Сайт работает на своём сервере:
Hostinger KVM 4 во Франкфурте, Ubuntu 22.04, Node 24, MongoDB 7.0, nginx, pm2,
сертификат Let's Encrypt. Проверка снаружи `ops/smoke.sh --login` — 50 из 50.

Старый хостинг (sprinthost) остаётся включённым как путь отката минимум месяц.

**Этап 0 закрыт**, кроме одного пункта: проверить воспроизведение эфира с OBS
на живом iPhone. Он упирался в сервер — теперь сервер есть.

**10 сентября: вёрстка закончена, Tailwind ушёл из проекта полностью** — ноль
вхождений в шаблонах. В дизайн-системе главная и информационные страницы,
шапка и модалки кабинета, каталог, страница пользователя, переписка, админка
и обе страницы эфира — последние сделаны 10 сентября. Не переверстана одна
страница, карта заведений `/main`: она в редизайн не входила и держит на себе
остатки старых стилей. Вместе с фреймворком со страниц эфира сняты sweetalert,
font-awesome, video-js, PeerJS и дублирующая загрузка socket.io: ни одна
из этих библиотек там не вызывалась.

**В тот же день закрыта модерация**: жалобы с разбором в `/panel`, роль
`moderator`, ограничение аккаунта, стоп-эфир и гейт 18+. Ограничение
проверяется и на приёме RTMP — иначе оно обходилось целиком, потому что OBS
подключается к 1935 напрямую, минуя сайт.

У вёрстки появился свой прогон — `RUNNER=audit.mjs bash ops/browser-check.sh`:
двенадцать страниц в четырёх ширинах экрана, зоны нажатия, пустые ссылки,
блокирующие скрипты, обход всех внутренних ссылок.

**Вечером того же дня — фильтры каталога**: подкатегории, город эфира,
сортировка. Категории и города сведены в `server/config/catalog.js`.

Ближайшее: связь (Daily, звонки), затем трансляции под нагрузкой. Раздача на тысячи зрителей упирается не в тариф, а в CDN —
расчёт в журнале за 9 сентября.

Скрипты эксплуатации и ловушки в проверках — [ops/README.md](ops/README.md).
Остальная документация ведётся в `docs/` рабочей копии и в репозиторий не идёт.
